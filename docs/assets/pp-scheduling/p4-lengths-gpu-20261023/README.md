# P4：新增长度的三卡训练对照

此前真机训练使用一种输入池：合成 token，序列训练长度为 193/129/33/17。三次运行是相同输入的不同对照，不是三种长度分布。本轮新增三个输入池，只记录真机执行结果。

模型不变：6 层、hidden512、FFN1024、4 heads、head-dim128，BF16，PP3/VPP2，chunk64，零 dropout。每个输入池生成 128 个文档；token 按整数顺序构造，每个原始文档比训练长度多一个预测标签 token。数据以 seed1234 采样，每次训练三步；同一输入池的各对照使用相同数据顺序、初始参数、Adam、LR 1e-3→1e-4 和确定性 FA。使用原有数值容差，未放宽。

一共完成 8 次训练、每次 3 步：三组融合 B 基线、三组实测成本 B，以及边界/长短混合两组构造成本 B。构造成本只在测试进程中提供给规划器，调用实际算法 B 搜索；算子、训练数据、容量校验、通信和状态管理都是真实执行，生产预测器的置信度门槛没有修改。无历史任务的诊断辅助脚本增加了空拆分集合处理。

- 五组候选运行共 45 份逐卡对照报告，outputs、dx、参数梯度、logits/loss、更新前后参数最大绝对差均为 0。相同输入、F/F、B/B、每 chunk W 次序及最终计划全卡一致检查通过。
- 边界组第二/三步实际执行 8/5 个 H，其中 2/3 个延后；长短混合组执行 11/1 个 H，其中 4/0 个延后。延后位置跨其他 B/D/H/W；三卡的 F/B 穿插发生改变。长短混合第三步的消息 FIFO 实际改变，按最终接收次序通信完成。
- 所有完成运行均无 optimizer 跳步或 NaN，每步各卡发送队列排空。整步 allocated 峰值均小于相应计数预留；所有候选的最大值约为 rank0 748.80 MiB、rank1 143.91 MiB、rank2 143.10 MiB。
- 三组实测成本 B 在新形状上均记录 `unreliable-compute-cost`，执行不拆分回退。它们验证回退与真实训练一致；自动拆分执行的证据来自明确标记的构造成本组，没有实测成本下的拆分收益结论。

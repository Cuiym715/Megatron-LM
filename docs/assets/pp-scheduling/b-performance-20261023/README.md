## 两种计时口径

吞吐统一为有效目标tokens除以三rank中最长的连续wall-clock区间。区间包含取数、训练、通信、显存检查、optimizer及正常训练循环开销；只在区间两端额外同步，没有逐任务计时或张量快照。

- **在线 B**：正常执行成本查询、供给编排、拆分搜索、协调节点广播及执行前校验。测量六步的协调入口耗时均值163.99ms，合计983.91ms；其中规划器内部记账均值157.71ms。首个预热步内部规划702.76ms，超过软预算621.90ms；后续七步均在预算内。
- **预存计划回放**：事先载入在线运行保存的计划，跳过在线成本查询、供给/拆分搜索及协调节点结果广播；仍构造同输入参考计划，保留执行侧校验、跨rank摘要核对、显存检查、通信和optimizer。它不是纯kernel时间，也不是从在线wall time中直接减CPU计时。全部八步的完整计划与在线B逐项相同。

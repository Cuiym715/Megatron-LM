## 开销定位

- 优化前后的异步B使用同一成本和同一任务顺序：10,601→10,747 tokens/s，提升1.38%。后台worker均值85.1→56.9ms；包含CPU输入准备等的完整规划均值114.8→86.4ms。

- 正常A/B/C及异步回放均采用worker结果，未因未就绪/失败改用原模板；预热后等待优化结果均为0ms。B和C的worker分别约56.9/84.1ms，均在上一轮任务区间内完成。B搜索决策约5.8ms，当前暂不继续迁移这部分Python图重放。
- 固定相同B计划，有后台真实求解比异步回放吞吐低1.61%；计算区间均值1386.0/1364.0ms，差1.61%。该区间包含host发射、流水线和通信等待；单次对照也包含运行波动，kernel耗时变化未单独测量。
- 预算保留单独B 60%、C总50%/其中B阶段30%；本批预热后没有规划预算超限。冷启动仍约6秒，不作为优化目标。
